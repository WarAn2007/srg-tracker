# Generated data

All project data is synthetic and reproducibly generated by
`src/generate_dataset.py`. No real student records, demographic attributes, or
OULAD rows are included.

From the repository root:

```powershell
.\.venv\Scripts\python.exe -m src.generate_dataset
```

The command overwrites `data/processed/train.csv`, `validation.csv`, `test.csv`,
`split_summary.csv`, and `data_quality_report.json` using seed `20260730`.

Do not combine the splits or randomly split weekly rows. Students are intentionally
disjoint to prevent the same learner from appearing in training and evaluation.
See `metadata/README.md` for the full dataset card.
