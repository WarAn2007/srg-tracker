# Data

The project data is synthetic and reproducibly generated by `src/generate_dataset.py`.

Run:

```powershell
python src/generate_dataset.py
```

This creates `processed/train.csv`, `processed/validation.csv`, `processed/test.csv`, and `processed/split_summary.csv`.

See [metadata/README.md](metadata/README.md) for the data dictionary, target definitions, generation assumptions, split strategy, and responsible-use restrictions.
